# Paddock 101

Scroll-driven 3D guide to Formula 1, from beginner to enthusiast.

Built with Vite, Three.js, GSAP ScrollTrigger and Lenis.

## Run

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # outputs dist/
```

`vite.config.js` uses a relative base, so `dist/` also works from a sub-path such as GitHub Pages.
